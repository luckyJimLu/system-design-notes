# 第 9 章：设计网络爬虫

## 简介
**网络爬虫**，也称为蜘蛛或机器人，用于发现和收集网络内容，例如网页、图像和视频。本章重点介绍为**搜索引擎索引**设计可扩展的网络爬虫。

### 网络爬虫的应用
1. **搜索引擎索引：**收集网页以创建可搜索索引（例如，Googlebot）。
2. **网络存档：** 保留网络数据以供将来使用（例如美国国会图书馆）。
3. **网络挖掘：** 从网络数据中提取知识（例如股东报告的财务分析）。
4. **网络监控：** 检测版权或商标侵权行为。

### 设计挑战
一个好的网络爬虫必须解决：
- **可扩展性：** 使用并行化处理数十亿个页面。
- **稳健性：** 管理不良 HTML、崩溃和恶意链接。
- **礼貌：** 避免因太多请求而导致服务器不堪重负。
- **可扩展性：** 只需进行最少的更改即可支持新的内容类型。

---

## 第 1 步：了解问题

### 要求
1. 抓取**每月 10 亿页**（400 页/秒，峰值 800 QPS）。
2. 收集**纯 HTML 内容**。
3. 跟踪新的和更新的页面。
4. 忽略重复的内容。
5. 将爬网数据存储 **5 年**，需要约 30 PB 的存储空间。

## 第 2 步：高层设计

### 组件

1. **种子 URL：** 爬网程序的起点。
    - 需要选择一个好的起点，让爬虫可以利用它来遍历尽可能多的链接。
    - 可以基于位置、基于不同的流行网站或基于主题。
    - 策略：按地点或主题（例如体育、医疗保健）分类。

2. **URL Frontier：** 存储要下载的URL。
   - 作为**先进先出队列**实现。

3. **HTML 下载器：** 从 URL Frontier 提供的 URL 下载网页。

4. **DNS 解析器：** 将 URL 转换为 IP 地址。

5. **内容解析器：** 验证并解析网页。
   - 丢弃格式错误的页面。

6. **看到的内容？：** 使用哈希比较检查重复内容（比较两个网页的哈希值）。

7. **内容存储：** 将 HTML 页面存储在磁盘上（常用内容存储在内存中以减少延迟）。

8. **URL 提取器：** 从解析的页面中提取新链接。

9. **URL 过滤器：** 排除列入黑名单或错误的 URL。

10. **已看到 URL？** 跟踪访问过的 URL 以避免重复。

11. **URL 存储：** 存储已访问过的 URL。


---

### 工作流程
1. 将 **种子 URL** 添加到 URL 边界。
2. **HTML 下载器** 获取 URL 并通过 DNS 解析器解析其 IP。
3. **内容解析器**验证内容并将其传递到“内容已看到？”成分。
4. 如果内容是新的，请通过 **URL 提取器** 提取链接。
5. 过滤并将唯一链接添加到 URL Frontier。

## 第 3 步：深入研究关键组件
### 深度优先搜索/广度优先搜索
-  网络可以被视为一个有向图，其中网页是节点，超链接 (URL) 是边。
-  BFS 通常用于图遍历，因为深度可能很深，因此 DFS 并不理想。
-  标准 BFS 不考虑 URL 的优先级，并非每个页面都具有相同的质量和重要性级别。


### 网址前沿
- **礼貌：**
    - 确保每个主机一次仅发出一个请求。添加大量黑白两个下载任务。
    - 使用从主机名到队列和工作（下载）线程的映射。
    - 每个下载器线程都有一个单独的 FIFO 队列，并且仅从该队列下载 URL。

        <img src="./images/politeness.png" alt="Politeness" width="500">

    - **队列路由器：** 确保每个队列（b1、b2、... bn）仅包含来自同一主机的 URL。
    - **映射表：**它将每个主机映射到一个队列。
    - **队列选择器：** 每个工作线程都映射到一个 FIFO 队列，并且它只从该队列下载 URL。队列选择逻辑由队列选择器完成。
    - **工作线程 1 到 N。** 工作线程从同一主机顺序下载网页。可以在两个下载任务之间添加延迟。

- **优先级：**
    - 为重要页面分配更高的优先级（例如，按 PageRank 或更新频率）。

        <img src="./images/prioritizer.png" alt="Politeness" width="500">
    
    - **Prioritizer：** 它以 URL 作为输入并计算优先级。
    - **队列 f1 到 fn：** 每个队列都有指定的优先级。具有高优先级的队列被选择的概率较高。
    - **队列选择器：** 随机选择一个队列，偏向于优先级较高的队列。
    - **前端队列：**管理优先级
    - **后排：**管理礼貌

- **新鲜度：** 根据更新历史记录或重要性重新抓取。


### HTML下载器
- **Robots.txt 合规性：** 尊重 robots.txt 文件中的规则。
- **性能优化：**
  1. 使用多个服务器进行分布式抓取。
  2. 使用 **DNS 缓存** 以避免重复查找。
  3. 按地理位置分布爬行服务器以加快下载速度。
  4. 使用较短的超时以避免服务器缓慢或无响应。

### 稳健性
1. **一致哈希：** 在服务器之间有效分配负载。
2. **错误处理：**防止系统因异常而崩溃。
3. **数据验证：** 确保内容完整性。

### 可扩展性
- 添加新内容类型的模块（例如 PNG 下载器、网络监视器）。
- 示例：插入一个模块来监控 Web 内容是否侵犯版权。

    <img src="./images/extensibility.png" alt="Politeness" width="600">
---

### 避免有问题的内容
1. **重复内容：** 使用哈希比较进行检测。
2. **蜘蛛陷阱：** 使用 URL 长度限制等技术避免无限循环。
3. **数据噪音：** 过滤不相关的内容，例如广告或垃圾邮件。

---

## 第四步：总结
### 要点
1. 网络爬虫必须平衡可伸缩性、稳健性、礼貌性和可扩展性。
2. **礼貌**可防止服务器超载，而**优先级**可确保首先抓取重要页面。
3. 高效的存储和错误处理对于处理大规模爬行至关重要。

### 其他注意事项
- **服务器端渲染：** 处理由 JavaScript 或 AJAX 生成的动态内容。
- **反垃圾邮件措施：** 排除低质量或不相关的页面。
- **数据库分片：** 使用复制和分片扩展数据层。
- **水平扩展：** 使用无状态服务器有效地扩展爬网作业。
- **分析：**收集和分析数据以获得见解。
